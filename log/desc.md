# 任务与模型说明(csvport 组合交易优化器)

- 对应代码:`golang_mosek/src/opt/solver.go`、`types.go`
- 运行记录见:`run_sample.md`(sample 利率互换)、`run_real.md`(optim_inputs 日股)

---

## 1. 业务问题

机构组合(债券/互换/股票)每天收到 alpha 信号(预期涨跌),但调仓受限于:

- **单品种**:交易量上下限、最终持仓上下限(借贷/流动性/风控限制)
- **组合层**:总敞口(gross)、净敞口(net)、按币种/行业/风险因子(BARRA)的
  分块敞口上限
- **交易成本**:手续费等线性成本 `cost·|x|`

输出即 `output.csv` 的 `targetTrade`:每个品种今天的最优交易量。

## 2. gross / net 的含义

四种约束类型(均由 weight.csv 给出每品种系数 w):

| type | 数学形式 | 含义 |
|---|---|---|
| `NET` | `lb ≤ Σ wₖ·(posₖ+xₖ) ≤ ub` | **期末净头寸**(带符号,多空相抵)。例:+100万 与 −90万 对冲后 net=+10万 |
| `GROSS` | `Σ wₖ·|posₖ+xₖ| ≤ ub` | **期末总头寸**(绝对值加总,lb 恒为 0)。同例 gross=190万 |
| `NET_TRADE` / `GROSS_TRADE` | 把 `pos+x` 换成 `x` | 同样概念,作用在**交易量**上 |

都作用在**交易后的最终持仓**上。BARRA 因子约束是 NET:w 为因子暴露,
Σw·(pos+x) 即该因子的净敞口。

## 3. 原始优化问题

决策变量 `xᵢ` = 品种 i 的交易量,目标(最大化,均值-方差效用 + 交易成本):

```
max_x  Σᵢ [ αᵢ·(posᵢ+xᵢ) − costᵢ·|xᵢ| − (λᵢ/2)·(posᵢ+xᵢ)² − (tλᵢ/2)·xᵢ² ]
s.t.   单品种交易界/持仓界 + 四类组合约束
```

四项含义:预期收益 `α·(pos+x)`、交易成本 `cost·|x|`、持仓风险 `(λ/2)(pos+x)²`、
交易摩擦 `(tλ/2)x²`。

## 4. 转化为凸 QP(五步,每步等价)

1. **丢常数**:`α·pos`、`(λ/2)·pos²` 不含 x,不影响 argmax,删除
   (solver.go:183 注释)。
2. **展开平方**:`(λ/2)(pos+x)² = (λ/2)x² + λ·pos·x + const`。
3. **合并同类项**:
   - 线性 `(α − λ·pos)·x`(solver.go:192)
   - 二次 `−(λ+tλ)·x²` 填入 Q(solver.go:190;负号因
     `OBJECTIVE_SENSE_MAXIMIZE`,solver.go:381;MOSEK 目标为 `½xᵀQx + cᵀx`,
     故对角系数 −(λ+tλ))
4. **线性化 |·|**(QP 不接受不可微项):
   - 每品种加辅助变量 `uᵢ ≥ 0` 及两条线性约束 `u ≥ x, u ≥ −x`
     (solver.go:152-161),目标加 `−cost·u`:最大化自动把 u 压到 |x|
   - GROSS 的 `|pos+x|` 同理用 `gᵢ ≥ ±(posᵢ+xᵢ)`(solver.go:169-179),
     约束行变为 `Σw·g ≤ ub`(solver.go:291)
5. **常数移进约束界**:
   - NET:`Σw(pos+x) ∈ [lb,ub]` → `Σw·x ∈ [lb−Σw·pos, ub−Σw·pos]`
     (solver.go:202-208)
   - 持仓界并入变量界:`max(minTrade, minPos−pos) ≤ x ≤ min(maxTrade, maxPos−pos)`
     (solver.go:141-143)

**最终交给 MOSEK 的问题**:线性约束 + 对角二次目标的凸 QP:

```
max  Σ(αᵢ−λᵢposᵢ)xᵢ − Σcostᵢuᵢ − ½Σ(λᵢ+tλᵢ)xᵢ²
s.t. uᵢ ≥ ±xᵢ,  gᵢ ≥ ±(posᵢ+xᵢ),  Σwᵍᵏ·gₖ ≤ ub (GROSS),
     Σwₖxₖ ∈ 界 (NET/NET_TRADE),  变量界 (merged)
```

规模来源:每品种 3 变量(x,u,g)、4 约束行(u±、g±),再加每条组合约束 1 行
(sample:23 品种 → 69 变量/121 行)。

**无约束闭式解**:`x* = (α − λ·pos − cost)/(λ+tλ)` —— 边际为正才交易,
λ 越大越保守。sample 中唯一显著交易 `USD_10Y5Y +5082` 即净边际 0.032 除以
6.27e-6,与该闭式一致。

## 5. 两阶段稳健求解(solver.go `Solve`)

1. **预处理**:当前持仓叠加交易界已破持仓界时,先放宽单品种持仓界
   (保证单品种永远可行,solver.go:31-38)。
2. **正常求解**:全部硬约束,可行即返回。
3. **Relax 模式**:仅当"零交易都违约"(账本本身已破线,任何交易救不回)时,
   持仓界锚定到当前持仓,违约约束界放宽为"不比今天更差",并引入弹性变量
   tₖ ≥ 违约量、按 `--elastic-penalty`(默认 100)线性惩罚,在可行域内尽量把
   解拉回原约束(solver.go:211-255, 298-321)。

另可选 `-s/--soft-lambda > 0`:对约束值加二次软惩罚(约束仍为硬约束,
solver.go:257-267)。

## 6. 模型谱系:各项目是否出自公认模型

每一项都能追溯到经典模型,但本代码是它们的**简化/退化版本**:

| 代码中的项 | 谱系(公认模型) | 简化点 |
|---|---|---|
| `λᵢ(posᵢ+xᵢ)²` 持仓风险 | **Markowitz (1952) 均值-方差** 效用 `αᵀx − (γ/2)xᵀΣx` | Q 只有对角:丢掉完整协方差 Σ 的交叉项,可理解为 `λᵢ = γ·σᵢ²`(只留各品种自身方差)。跨品种对冲/相关性不进目标函数,而由 BARRA 因子 NET 约束控制(MSCI Barra 多因子模型,本身也是行业标准) |
| 惩罚持仓**水平**而非方差 | 更接近**库存风险**模型,如 Avellaneda–Stoikov (2008) 做市的 `γq²` 库存惩罚 | 经典均值-方差惩罚的是围绕基准的方差;这里惩罚绝对持仓量("持有任何敞口都有罪"),把组合往零推 |
| `(tλᵢ/2)xᵢ²` 交易摩擦 | **Kyle (1985)** 线性价格冲击 `p = λ_kyle·x` 积分得 `(λ/2)x²`;**Almgren–Chriss (2000)** 最优执行的二次暂时冲击;Grinold–Kahn《Active Portfolio Management》实施成本章 | 实证上著名的是平方根定律(冲击 ∝ √x),x² 是为保持凸 QP 可解的标准凸近似,同时天然惩罚单品种交易集中度 |
| `cost·|x|` 线性成本 | 最古典的交易成本(点差+手续费) | 无 |

**结论**:

- 整体框架 = "均值-方差 + 线性/二次交易成本"的单期交易目标,学术与业界
  标准形(如 Gärleanu–Pedersen (2013)、Grinold–Kahn 的 implementation
  shortfall 框架),非杜撰。
- 两个关键退化:① 协方差结构不在目标函数里(对角 Q + 因子线性约束替代);
  ② 持仓惩罚是水平平方而非相对基准的方差。故严格说是
  **Markowitz 风格效用 + Kyle/Almgren-Chriss 式冲击成本的最小可运行版本**,
  而非任何一个模型的完整形态。
- λ、tλ 为可调风险厌恶系数,由上游数据生产方给定——模型形式公认,参数是私货。
